# First Steps
This section includes content that precedes interacting with our HPC systems directly. This includes, but is not limited to:

- A discussion on HPC in general
- Setting up Secure Shell (SSH) keys for remote connection
- The initial log-on process
- Setting up required two-factor authentication (2FA) for future 

If you run into trouble while reading these guides, please email [hpchelp@gwu.edu](mailto:hpchelp@gwu.edu) with detailed information on your particular issues. Someone will be able to assist as soon as available, thank you very much for using our resources!
